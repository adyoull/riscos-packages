RISC OS packages

Ports and applications by Andrew Youll, for PackMan.

Adding this source to PackMan

In PackMan, choose Sources… from the icon bar menu, add

https://adyoull.github.io/riscos-packages/pkg/index

then choose Update lists. The packages below then show in PackMan with the rest.
